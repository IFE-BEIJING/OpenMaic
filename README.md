# OpenMAIC · AI 互动课堂平台

输入一个主题或上传一份文档，AI 自动生成一套可播放的互动课件：幻灯片、语音讲解、插图、测验与项目式学习（PBL）活动。播放时由"AI 老师 + AI 同学"多角色语音讲课、白板绘图，学习者可实时参与讨论。

## 功能特性

- **一键生成课堂** — 主题或文档自动产出大纲、逐页幻灯片（含白板动画脚本）、TTS 旁白、AI 插图/视频、测验与 PBL
- **沉浸式播放** — 多角色语音讲解、动作级导航、深度交互（3D 可视化、模拟实验、思维导图等）
- **实时互动** — 语音/文字讨论、测验作答、笔记生成与导出
- **AI 编辑器** — 幻灯片元素直接编辑（拖拽/缩放）+ "Edit with AI" 校验式 AI 修改
- **课件分享** — 链接分享，未登录访客只读（仅笔记，隐藏对话交互）
- **管理后台** — 用户管理、课程管理（分页/关键字搜索/Excel 导出）、系统配置、用量统计
- **视频导出** — 一键导出 MP4 课程视频
